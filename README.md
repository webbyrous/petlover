### 🐾 Pet Adoption Website
A responsive pet adoption website built with React and Vite. The application connects to the RescueGroups API to display dogs and cats that are currently available for adoption and provides users with detailed information about each animal. The main goal of the project is to create a simple, accessible and responsive interface that makes it easier for users to discover pets looking for a new home.

# 🛠️ Technologies
- React
- Vite
- JavaScript
- Tailwind CSS
- RescueGroups API
- React Icons
- Git & GitHub

# Main folders
- components/ — Reusable UI components used throughout the application.
- pages/ — Main pages of the website.
- services/ — API requests and functions related to external data.
- assets/ — Images and other static assets used by the application.

# ✨ Features
- Browse animals currently available for adoption.
- View detailed information about each animal.
- Responsive design for desktop, tablet and mobile devices.
- Integration with the RescueGroups API.
- Dynamic animal data and images.
- Responsive navigation menu.
